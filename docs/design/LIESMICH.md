# VALORE Design-Paket (Stand 31.10.2026)

Zweck: Grundlage, damit eine neue Kurs-Plattform GENAU wie die VALORE-Webseite aussieht.
Quelle: Repo Edmund00/valorebusinessclub (main, 746c3f8) und Live-Seite; nur gelesen, nichts geändert.

Reihenfolge zum Lesen:
1. 01_DESIGN-BESCHREIBUNG.md (alle 13 Punkte, Codeausschnitte direkt aus dem echten CSS)
2. design-tokens.css (Farben und Schriften als Variablen, zum direkten Einfügen)
3. css/ (die echten CSS-Dateien: startseite-inline.css, shop-style.css, fonts.css, ...)
4. fonts/ (selbst gehostete woff2-Dateien; Pfade in css/fonts.css zeigen auf /assets/fonts/, bei Bedarf anpassen)
5. logos/ und referenz/startseite-struktur.html (HTML-Aufbau, ohne Skripte, Nummern, Mail-Adressen und Formular-Codes)

Hinweis: Das Repo enthält mehrere Stile. Gemeint ist der Haupt-Stil (Gold/Elfenbein, Jost, Cormorant Garamond). Details in Abschnitt 13.
